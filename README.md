# DramaDial

DramaDial is a client side holiday seating planner that allows users to adjust harmony or chaos using two drama dials.

## Features
- Add guests with vibe tags
- Load guest templates
- Drag and drop seating
- Optimize seating for harmony or chaos
- Export seating layout to PNG
- Print ready PDF layout
- Fully local browser app

## Files
- `dramadial.html` . main app
- `guest_templates.md` . template library
- `README.md` . documentation

## Installation
No installation required. Just open `dramadial.html` in your browser.

## GitHub Pages
To host DramaDial.

3. Enable GitHub Pages
